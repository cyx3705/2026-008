# 2026-008-英语四级学习

> 大学英语四级学习资料，涵盖单词单元、翻译短篇抄写与近年真题试卷

## 项目内容

1. **四级单词**
`a1-四级单词` 收录四级单词学习文档，含 U1 至 U10 共十个单元，以及一份 `模板.docx`。
2. **四级翻译**

- 翻译题目：`四级翻译题目1.docx`；
- 短篇抄写：`四级翻译短篇抄写1.docx` 至 `四级翻译短篇抄写12.docx`，另含 A5 版（第 6、7 篇）及 `四级翻译短篇抄写n.docx`。

3. **四级试卷**

- 2025 年 6 月真题：三套试卷 PDF 与答案，第 1、2 套另配听力 MP3；
- 2025 年 12 月真题：三套试卷 PDF 与答案，第 1、2 套另配听力 MP3。

4. **参考资料**

- 《2026年6月 晓艳英语四级急救班讲义.pdf》；
- 《【英语四级你还在背单词吗】电子课本(1).pdf》。

## 宿主模块

四级抄写模块版本 0.6.1，适用 HistoryVulcan 7.0.0。接入和数据边界见 [现行约定](b-Office/现行约定.md)，功能见 [模块说明](b-code-lerningtool/README.md)。发布使用宿主模块开发管线，不再使用旧目录包脚本。
